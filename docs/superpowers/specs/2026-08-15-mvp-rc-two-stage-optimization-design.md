# 神评卡片 MVP 发布前二阶段排查优化 Spec

日期：2026-08-15  
状态：设计已确认，暂不实施  
首发平台：B站网页版视频详情页

## 1. 目标与阶段

### 阶段一：功能修复与制作体验升级

- 保留 `3:4`，将现有竖版 `9:16` 替换为横版 `16:9`。
- 趣味属性成为独立开关，默认关闭。
- 评论正文块在安全内容区内纵向居中。
- 使用本地 `bilibili` 英文品牌字标。
- 品牌字标与视频标题同一行；标题单行超出显示省略号。
- 制作面板改为可拖动、非模态悬浮面板。
- 评论正文允许本次卡片内修改，并可恢复原文。
- 增加制作动画和默认关闭的简单声效。
- 制作后先显示预览，用户确认后才下载 PNG。
- 预览默认轻微 3D 往返摆动，鼠标进入或键盘聚焦后暂停。
- 搭建样式资源目录，不接入现有运行时。

### 阶段二：发布前排查与收口

- 完整配置组合、文本边界、封面降级和真实 B站验收。
- 视觉快照、精确导出尺寸、无障碍、reduced-motion、声效和控制台检查。
- 权限、隐私和本地资源审计。
- 生成 RC ZIP、校验文件和发布说明。
- 只修复排查发现的问题，不新增产品能力。

## 2. 核心流程前后对比

修复前：

```text
选择评论 → 简单确认卡 → 点击生成 → Canvas 静态生成 → 立即下载 → 完成提示
```

修复后：

```text
选择评论
→ 可拖动悬浮制作面板
→ 编辑文字与选项
→ 点击“制作卡片”
→ 光核收束 + 少量粒子 + 可选轻声效
→ Canvas 本地渲染
→ 旋转卡片预览
→ 鼠标进入预览暂停
→ 确认保存 / 返回修改
→ 确认后下载 PNG
```

## 3. 比例与画布

```ts
type CardRatio = "3:4" | "16:9";
```

- `3:4`：`1200 × 1600`，默认。
- `16:9`：`1920 × 1080`，横版。
- 检测到旧偏好 `9:16` 时重置为 `3:4`，不静默映射为方向完全不同的横版。

### 3.1 横版布局

```text
┌────────────────────────────────────┐
│ bilibili  视频标题……                │
├──────────────┬─────────────────────┤
│              │                     │
│   视频封面    │  纵向居中的评论正文   │
│              │                     │
│              │      昵称 / 时间     │
├──────────────┴─────────────────────┤
│ 可选趣味属性                         │
└────────────────────────────────────┘
```

- 有封面时位于左侧，占宽约 `30%–38%`。
- 长文本可压缩封面，但不得低于安全宽度。
- 无封面时正文使用全部内容宽度，不保留空占位。
- 横版必须独立计算字号、换行、安全区和署名位置，不能压缩竖版坐标。

## 4. 生成选项与偏好

```ts
interface GenerateOptions {
  style: "warm" | "history" | "sarcasm" | "sss";
  ratio: "3:4" | "16:9";
  includeCover: boolean;
  includeAttributes: boolean;
  gameDecoration: boolean;
  soundEnabled: boolean;
}
```

默认：

```ts
{
  ratio: "3:4",
  includeAttributes: false,
  gameDecoration: false,
  soundEnabled: false,
}
```

趣味属性与游戏化装饰独立：属性关闭时完全移除属性区并扩展正文区域；游戏化装饰仅控制评级徽记、能量纹路和额外装饰。编辑后的评论、拖动位置、预览和视频标题不得进入持久化存储。

## 5. 正文纵向居中

正文块在扣除平台标题行、署名时间、可选属性区、边框和装饰安全边距后的内容区中纵向居中：

```text
y = safeTop + (safeHeight - measuredTextHeight) / 2
```

- 短文本明显居中。
- 中等文本保持视觉平衡。
- 长文本先缩小字号，再截断。
- 正文不得覆盖昵称、时间或属性区。
- 中文、英文、Emoji、混排和主动换行均使用实际测量高度。

## 6. bilibili 字标与视频标题

扩展数据对象：

```ts
interface CommentCardSource {
  platform: "bilibili";
  content: string;
  authorName?: string;
  publishedAt?: string;
  videoCoverUrl?: string;
  videoTitle?: string;
}
```

- 使用本地内置 `bilibili` 英文品牌字标 SVG，不使用当前简化电视机图标，不运行时请求外部 Logo。
- 字标与标题位于同一行，保持原比例，不拉伸。
- 标题读取优先级：`og:title` → 视频页主标题 → `document.title`。
- 合并多余空白并去除重复站点后缀。
- 标题缺失不阻止生成，仅显示字标。
- Canvas 通过 `measureText()` 将标题截成单行并使用 `…`。

## 7. 悬浮制作面板

- 非模态，默认位于页面右侧，不遮罩整页。
- 用户仍可滚动评论区。
- 仅标题栏可拖动；输入框、表单和按钮不得触发拖动。
- 面板始终限制在视口内，resize 后重新约束。
- 位置只保留在当前标签页生命周期，刷新后恢复默认。
- 选择评论后固定当前来源；点击“重新选择”才返回选择状态。

面板状态：

```ts
type CreationPanelState = "editing" | "generating" | "preview" | "error";
```

### editing

- 评论文字编辑框与“恢复原文”。
- 风格、比例、封面、趣味属性、游戏化装饰、声效开关。
- 重新选择、取消、制作卡片。

### generating

- 表单不可操作，禁止重复触发。
- 面板收束为光核并显示制作动画。
- 可明确取消尚未完成的任务。

### preview

- 展示最终 Canvas/Blob 预览。
- 提供“确认保存”和“返回修改”。
- 不自动下载。

### error

- 卡片式错误提示。
- 提供重试和返回修改。
- 保留编辑稿和所有选项。

## 8. 评论文字编辑

```ts
interface CommentDraft {
  originalContent: string;
  editedContent: string;
}
```

- 编辑只影响当前卡片，不修改 B站页面、不写入 storage。
- 提供恢复原文。
- 切换评论时重新初始化并丢弃旧草稿。
- 生成使用 `editedContent.trim()`，为空时禁止制作。
- 保留用户主动换行。
- 趣味属性开启时，以编辑后的正文作为稳定种子。
- 返回修改时保留草稿和选项。

## 9. 制作动画与声效

建议动画总时长 `900–1400ms`：

```text
0–200ms   面板轻微收束
200–500ms 渐变光核形成
400–900ms 12–20 个轻粒子聚合卡片轮廓
完成      最终卡片进入预览
```

动画与实际渲染并行：

```ts
await Promise.all([renderCard(), playMinimumGenerationAnimation()]);
```

- 不伪造百分比进度。
- 渲染较慢时保持低强度循环，完成后自然进入预览。
- 优先 CSS transform/opacity；不引入大型动画库或复杂 3D。
- 页面隐藏时停止动画。
- reduced-motion 下取消收束、粒子和旋转，只使用短淡入。

声效开关默认关闭。开启后播放短促启动音与更轻的完成音，总时长小于约 `500ms`，不得循环、不得网络请求；声效失败不影响制作。

## 10. 预览与确认保存

- 预览必须直接来自最终 Canvas 或其 Blob，避免双渲染偏差。
- 默认在 `rotateY(-6deg)` 与 `rotateY(6deg)` 间以 `3.5–5s ease-in-out` 往返。
- 鼠标进入、键盘聚焦预览或按钮时暂停；离开后恢复。
- reduced-motion 下保持静态。

按钮：

- `确认保存`：下载 PNG，随后显示保存完成。
- `返回修改`：保留草稿和选项，释放旧预览资源。

关闭未保存预览时给予轻量提示，确认关闭后释放 Canvas/Blob/Object URL，不自动下载。

## 11. 导出服务拆分

```ts
interface PngArtifact {
  blob: Blob;
  objectUrl: string;
  width: number;
  height: number;
}

createPngArtifact(canvas): Promise<PngArtifact>
downloadPngArtifact(artifact, filename): Promise<void>
```

- 制作完成时创建 artifact。
- 预览复用同一 artifact。
- 用户确认时才下载。
- 返回修改、再次制作、关闭或销毁时撤销旧 Object URL。
- 每次确认最多触发一次下载。

## 12. 样式资源目录预留

只搭建结构，不迁移现有主题、不接入运行时：

```text
src/card-styles/
├── README.md

│   └── .gitkeep
├── border/
│   └── .gitkeep

│   └── .gitkeep
```

- `background/`：背景纹理、纸张、渐变、底图。
- `border/`：边框、角框、描边纹理。

- `effect/`：流光、粒子和光晕资源。

README 记录命名、许可、本地资源、安全区和禁止脚本规则。未来自定义样式必须采用声明式配置，不直接执行代码。本阶段禁止模板市场、用户上传、远程样式和运行时动态加载。

## 13. 阶段一测试

### 数据与适配器

- `9:16` 旧偏好归一为 `3:4`。
- 属性、游戏化和声效默认关闭。
- 编辑正文不进入 storage。
- 视频标题三级回退、后缀清理和缺失降级。

### Canvas

- `3:4` 有/无封面、属性开/关。
- `16:9` 有/无封面、属性开/关。
- 四种风格至少各有代表组合。
- 短文本纵向居中，长文本不覆盖署名。
- 标题单行省略，缺失标题布局正常。
- bilibili 字标比例正确。
- 游戏化与属性互不依赖。

### 制作面板

- 拖动、视口约束、resize 约束。
- 表单操作不触发拖动，页面滚动不关闭。
- 恢复原文、空正文拦截、返回修改保留草稿。
- 生成中禁止重复操作。

### 预览与导出

- 声效默认关闭且失败不影响生成。
- 确认前不下载；确认后只下载一次。
- 返回修改不下载。
- 旧 Object URL 在所有生命周期节点释放。
- hover/focus 暂停旋转。
- reduced-motion 关闭制作与预览循环动画。

## 14. 阶段二排查矩阵

采用核心基线和配对覆盖，不穷举全部组合：

| 风格 | 比例 | 封面 | 属性 | 游戏化 |
| --- | --- | --- | --- | --- |
| 温暖 | 3:4 | 开 | 关 | 关 |
| 历史 | 3:4 | 关 | 开 | 关 |
| 嘲讽 | 16:9 | 开 | 关 | 开 |
| SSS | 16:9 | 关 | 开 | 开 |

额外保证每种风格在两种比例下至少出现一次，每个开关的开关状态至少覆盖一次，默认配置有独立 E2E，所有导出尺寸精确。

文本边界包括：极短中文、普通中文、超长中文、英文长词、中英混排、Emoji、主动换行、空白文本、缺昵称、缺时间、超长标题和缺标题。

封面边界包括：正常、跨域失败、404、超时、无封面、横图、竖图和极端宽高比。

真实 B站必须检查：顶层与默认回复、选择动画、面板拖动、文本编辑、四风格、两比例、默认开关、标题、制作动画、声效、预览暂停、返回修改、确认保存、五种退出、页面原生交互和控制台。

## 15. 权限、隐私与 RC 产物

生产权限保持 `storage` 与 `downloads`，不得增加远程脚本、通配 host permission、评论历史、网络音频或上传能力。

RC 产物：

```text
release/
├── comment-card-extension-0.2.0-rc.1.zip
├── SHA256SUMS.txt
└── release-notes-0.2.0-rc.1.md
```

建议 Manifest 使用 `version: "0.2.0"`、`version_name: "0.2.0-rc.1"`。本阶段不自动发布 Chrome Web Store，也不 push。

发布说明明确：仅支持 B站视频页、顶层评论和默认展示回复；比例为 `3:4` 与横版 `16:9`；本地生成下载；折叠回复、分页和其他平台不支持；声效默认关闭；文字编辑只影响当前卡片。

## 16. 完成标准

阶段一完成必须满足：新增能力均有 RED/GREEN；两种比例正确；属性默认关闭；正文纵向居中；字标与单行标题正确；悬浮面板可拖动；文字可编辑恢复；制作动画、声效开关和旋转预览可用；用户确认后才下载；样式目录仅完成结构。

阶段二完成必须满足：自动化与 RC 矩阵通过；真实 B站通过；无未解释 console error；Manifest 权限和本地资源通过；生成 ZIP、校验文件和发布说明；验收文档与实际结果一致。
