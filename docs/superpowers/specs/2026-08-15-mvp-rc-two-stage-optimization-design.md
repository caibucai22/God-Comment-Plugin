# 神评卡片 MVP 发布前二阶段排查优化 Spec

日期：2026-08-15  
状态：设计已确认，暂不实施  
首发平台：B站网页版视频详情页

## 1. 目标与阶段

### 阶段一：功能修复与制作体验升级

- 保留 `3:4`，将现有竖版 `9:16` 替换为横版 `16:9`。
- 趣味属性成为独立开关，默认关闭。
- 评论正文块在安全内容区内纵向居中。
- 使用本地 `bilibili` 英文品牌字标。
- 品牌字标与视频标题同一行；标题单行超出显示省略号。
- 制作面板改为可拖动、非模态悬浮面板。
- 评论正文允许本次卡片内修改，并可恢复原文。
- 增加制作动画和默认关闭的简单声效。
- 制作后先显示预览，用户确认后才下载 PNG。
- 预览默认轻微 3D 往返摆动，鼠标进入或键盘聚焦后暂停。
- 搭建样式资源目录，不接入现有运行时。

### 阶段二：发布前排查与收口

- 完整配置组合、文本边界、封面降级和真实 B站验收。
- 视觉快照、精确导出尺寸、无障碍、reduced-motion、声效和控制台检查。
- 权限、隐私和本地资源审计。
- 生成 RC ZIP、校验文件和发布说明。
- 只修复排查发现的问题，不新增产品能力。

## 2. 核心流程前后对比

修复前：

```text
选择评论 → 简单确认卡 → 点击生成 → Canvas 静态生成 → 立即下载 → 完成提示
```

修复后：

```text
选择评论
→ 可拖动悬浮制作面板
→ 编辑文字与选项
→ 点击“制作卡片”
→ 光核收束 + 少量粒子 + 可选轻声效
→ Canvas 本地渲染
→ 旋转卡片预览
→ 鼠标进入预览暂停
→ 确认保存 / 返回修改
→ 确认后下载 PNG
```

## 3. 比例与画布

```ts
type CardRatio = "3:4" | "16:9";
```

- `3:4`：`1200 × 1600`，默认。
- `16:9`：`1920 × 1080`，横版。
- 检测到旧偏好 `9:16` 时重置为 `3:4`，不静默映射为方向完全不同的横版。

### 3.1 横版布局

```text
┌────────────────────────────────────┐
│ bilibili  视频标题……                │
├──────────────┬─────────────────────┤
│              │                     │
│   视频封面    │  纵向居中的评论正文   │
│              │                     │
│              │      昵称 / 时间     │
├──────────────┴─────────────────────┤
│ 可选趣味属性                         │
└────────────────────────────────────┘
```

- 有封面时位于左侧，占宽约 `30%–38%`。
- 长文本可压缩封面，但不得低于安全宽度。
- 无封面时正文使用全部内容宽度，不保留空占位。
- 横版必须独立计算字号、换行、安全区和署名位置，不能压缩竖版坐标。

## 4. 生成选项与偏好

```ts
interface GenerateOptions {
  style: "warm" | "history" | "sarcasm" | "sss";
  ratio: "3:4" | "16:9";
  includeCover: boolean;
  includeAttributes: boolean;
  gameDecoration: boolean;
  soundEnabled: boolean;
}
```

默认：

```ts
{
  ratio: "3:4",
  includeAttributes: false,
  gameDecoration: false,
  soundEnabled: false,
}
```

趣味属性与游戏化装饰独立：属性关闭时完全移除属性区并扩展正文区域；游戏化装饰仅控制评级徽记、能量纹路和额外装饰。编辑后的评论、拖动位置、预览和视频标题不得进入持久化存储。

## 5. 正文纵向居中

正文块在扣除平台标题行、署名时间、可选属性区、边框和装饰安全边距后的内容区中纵向居中：

```text
y = safeTop + (safeHeight - measuredTextHeight) / 2
```

- 短文本明显居中。
- 中等文本保持视觉平衡。
- 长文本先缩小字号，再截断。
- 正文不得覆盖昵称、时间或属性区。
- 中文、英文、Emoji、混排和主动换行均使用实际测量高度。

## 6. bilibili 字标与视频标题

扩展数据对象：

```ts
interface CommentCardSource {
  platform: "bilibili";
  content: string;
  authorName?: string;
  publishedAt?: string;
  videoCoverUrl?: string;
  videoTitle?: string;
}
```

- 使用本地内置 `bilibili` 英文品牌字标 SVG，不使用当前简化电视机图标，不运行时请求外部 Logo。
- 字标与标题位于同一行，保持原比例，不拉伸。
- 标题读取优先级：`og:title` → 视频页主标题 → `document.title`。
- 合并多余空白并去除重复站点后缀。
- 标题缺失不阻止生成，仅显示字标。
- Canvas 通过 `measureText()` 将标题截成单行并使用 `…`。

## 7. 悬浮制作面板

- 非模态，默认位于页面右侧，不遮罩整页。
- 用户仍可滚动评论区。
- 仅标题栏可拖动；输入框、表单和按钮不得触发拖动。
- 面板始终限制在视口内，resize 后重新约束。
- 位置只保留在当前标签页生命周期，刷新后恢复默认。
- 选择评论后固定当前来源；点击“重新选择”才返回选择状态。

面板状态：

```ts
type CreationPanelState = "editing" | "generating" | "preview" | "error";
```

### editing

- 评论文字编辑框与“恢复原文”。
- 风格、比例、封面、趣味属性、游戏化装饰、声效开关。
- 重新选择、取消、制作卡片。

### generating

- 表单不可操作，禁止重复触发。
- 面板收束为光核并显示制作动画。
- 可明确取消尚未完成的任务。

### preview

- 展示最终 Canvas/Blob 预览。
- 提供“确认保存”和“返回修改”。
- 不自动下载。

### error

- 卡片式错误提示。
- 提供重试和返回修改。
- 保留编辑稿和所有选项。

## 8. 评论文字编辑

```ts
interface CommentDraft {
  originalContent: string;
  editedContent: string;
}
```

- 编辑只影响当前卡片，不修改 B站页面、不写入 storage。
- 提供恢复原文。
- 切换评论时重新初始化并丢弃旧草稿。
- 生成使用 `editedContent.trim()`，为空时禁止制作。
- 保留用户主动换行。
- 趣味属性开启时，以编辑后的正文作为稳定种子。
- 返回修改时保留草稿和选项。

## 9. 制作动画与声效

建议动画总时长 `900–1400ms`：

```text
0–200ms   面板轻微收束
200–500ms 渐变光核形成
400–900ms 12–20 个轻粒子聚合卡片轮廓
完成      最终卡片进入预览
```

动画与实际渲染并行：

```ts
await Promise.all([renderCard(), playMinimumGenerationAnimation()]);
```

- 不伪造百分比进度。
- 渲染较慢时保持低强度循环，完成后自然进入预览。
- 优先 CSS transform/opacity；不引入大型动画库或复杂 3D。
- 页面隐藏时停止动画。
- reduced-motion 下取消收束、粒子和旋转，只使用短淡入。

声效开关默认关闭。开启后播放短促启动音与更轻的完成音，总时长小于约 `500ms`，不得循环、不得网络请求；声效失败不影响制作。

## 10. 预览与确认保存

- 预览必须直接来自最终 Canvas 或其 Blob，避免双渲染偏差。
- 默认在 `rotateY(-6deg)` 与 `rotateY(6deg)` 间以 `3.5–5s ease-in-out` 往返。
- 鼠标进入、键盘聚焦预览或按钮时暂停；离开后恢复。
- reduced-motion 下保持静态。

按钮：

- `确认保存`：下载 PNG，随后显示保存完成。
- `返回修改`：保留草稿和选项，释放旧预览资源。

关闭未保存预览时给予轻量提示，确认关闭后释放 Canvas/Blob/Object URL，不自动下载。

## 11. 导出服务拆分

```ts
interface PngArtifact {
  blob: Blob;
  objectUrl: string;
  width: number;
  height: number;
}

createPngArtifact(canvas): Promise<PngArtifact>
downloadPngArtifact(artifact, filename): Promise<void>
```

- 制作完成时创建 artifact。
- 预览复用同一 artifact。
- 用户确认时才下载。
- 返回修改、再次制作、关闭或销毁时撤销旧 Object URL。
- 每次确认最多触发一次下载。

采用核心基线和配对覆盖，不穷举全部组合：

| 风格 | 比例 | 封面 | 属性 | 游戏化 |

## 17. 制作面板布局优化设计

本节由 `design-taste-frontend` skill 的改版审计方法补充。它用于约束后续实现，不表示本轮已修改产品代码。

### 17.1 Design Read 与设计参数

Design Read：这是面向 B站内容消费者的浏览器内制作工具改版，目标是轻量、可信、带一点收藏卡片质感，采用原生 CSS 与 Shadow DOM 的克制暗色工具面板。

```text
DESIGN_VARIANCE: 5
MOTION_INTENSITY: 5
VISUAL_DENSITY: 6
```

- `DESIGN_VARIANCE 5`：信息区域有主次和适度错落，但控件仍按稳定网格对齐。
- `MOTION_INTENSITY 5`：动效只表达拖动反馈、制作进度和状态切换。
- `VISUAL_DENSITY 6`：保留紧凑工具感，同时保证正文编辑和按钮有足够触达面积。
- 这是产品工具面板，不套用营销落地页结构，也不新增 React、Tailwind、Motion 或组件库。
- 设计采用针对性演进，保留 Shadow DOM、既有事件名称、中文操作文案和退出语义。

### 17.2 现状审计

当前结构：

```text
流光卡片核 / 生成前确认
只读评论预览
风格单选
比例单选
封面与游戏化复选框
取消 / 生成卡片
```

应保留：

- Shadow DOM 隔离，避免污染 B站页面。
- 入口、选择提示、确认区和状态提示使用同一视觉语言。
- 四种风格和清晰的中文操作标签。
- reduced-motion 兜底、原生表单语义和销毁后事件惰性。

应淘汰：

- `286px` 固定窄卡，无法承载可编辑正文、更多开关和预览。
- 全部区域都使用相同卡片边框和发光，缺少主次。
- 标题、副标题、流光背景和渐变按钮同时抢占视觉焦点。
- 表单项依赖紧凑换行，选项增加后容易产生参差布局。
- 只读 blockquote 不适合评论修改，也没有恢复原文和字数状态。
- 动作区随内容滚动，不利于长正文和小视口操作。
- `generating`、`preview`、`error` 只以外部状态卡补充，无法建立连续制作心智模型。

### 17.3 视觉方向

面板采用“暗色编辑台 + 单一电蓝强调色”，不默认游戏化包装。

- 基础表面：中性冷灰近黑，不使用纯黑。
- 强调色：单一 B站蓝方向的低饱和电蓝，用于焦点、选中和主要按钮。
- 风格色只出现在风格选择项的小面积预览中，不改变面板主题。
- 面板不使用大面积紫蓝渐变，不使用持续外发光。
- 阴影只表达悬浮层级，使用带冷灰色相的柔和阴影。
- 圆角系统固定：面板 `16px`，输入和分组 `10px`，按钮 `10px`；开关轨道可使用全圆角。
- 字体沿用系统无衬线字体，正文优先中文可读性，不额外加载网络字体。
- 图标优先使用已有文字符号或单一成熟图标集；实现阶段不得临时混用多套图标。

建议语义色令牌：

```css
:host {
  --ccg-surface: #171a20;
  --ccg-surface-raised: #20242c;
  --ccg-surface-soft: #272c35;
  --ccg-border: rgba(220, 232, 244, 0.14);
  --ccg-text: #f3f6f9;
  --ccg-text-muted: #aeb8c5;
  --ccg-accent: #38bde8;
  --ccg-accent-strong: #179bc8;
  --ccg-danger: #ef7d8d;
  --ccg-success: #58c99c;
}
```

最终实现前必须用实际颜色重新校验 WCAG AA，不将这些草案值视为免检结果。

### 17.4 桌面布局

默认尺寸：

- 宽度 `360px`，可在 `340-420px` 范围内根据视口收缩。
- 最大高度 `min(720px, calc(100dvh - 32px))`。
- 默认距右侧和底部各 `16px`。
- 面板内部使用 `16px` 外边距和 `8px` 基础间距单位。
- 标题栏高 `52px`，底部动作区最小高 `64px`。

层级规则：

- 标题栏只保留产品名、拖动语义和关闭按钮，不再重复“生成前确认”。
- 来源摘要使用一块无额外卡片边框的紧凑区域，通过留白和一条底部分隔线分组。
- 作者和发布时间使用次级文字；视频标题独占下一行，单行省略。
- 正文编辑器是视觉主体，默认高 `132px`，允许在 `112-220px` 内随面板高度调整。
- “恢复原文”是文本按钮，只有内容被修改时提高可见度。
- 风格使用四列分段选择；每项至少 `44px` 高，文字不换行。
- 比例使用两列分段选择，并明确显示“16:9 横版”，避免只看数字误判方向。
- 四个布尔选项使用纵向列表，不嵌套成四张卡；行高不小于 `44px`。
- 开关说明和控件分别左右对齐，整行可点击。
- 底部动作区固定在面板内部，不随内容区滚走。
- “制作卡片”是唯一高强调按钮；“重新选择”为次要描边按钮，关闭不与取消生成重复表达。

### 17.5 滚动与拖动

- 仅中部内容区滚动，标题栏和动作区固定。
- 滚动条保持窄且可见，不用隐藏滚动条制造简洁感。
- 拖动命中区为标题栏空白和明确的拖动柄，关闭按钮不触发拖动。
- 拖动时只更新 `transform`，不连续修改 `top/left` 触发布局。
- 拖动开始时阴影略加深，结束后以 `160-220ms` 缓动贴合视口边界。
- 不使用磁吸、弹簧甩动或跟手倾斜，避免影响 B站页面浏览。
- 面板与视口至少保留 `8px` 安全边距。

### 17.6 小视口降级

当视口宽度小于 `480px` 或无法容纳默认面板时：

- 面板宽度变为 `calc(100vw - 16px)`，左右各留 `8px`。
- 面板停靠在底部，不允许自由拖出视口。
- 最大高度为 `min(78dvh, 680px)`。
- 风格仍为四列；若最小宽度不足则改为两列，不横向滚动。
- 底部按钮保持同一行；极窄时改为两列等宽，按钮文字仍不得换行。
- 不使用全屏遮罩，用户仍能看到当前 B站上下文。

### 17.7 状态原位替换

四个状态共享同一个面板外壳，避免弹出第二张卡片造成层级跳跃。

#### editing

- 展示完整表单。
- 空正文在编辑器下方显示内联错误，焦点移回编辑器。
- 封面不可用时开关禁用，并显示“当前视频封面不可用”，不只降低透明度。

#### generating

```text
┌──────────────────────────────────┐
│ 流光卡片核                    关闭 │
├──────────────────────────────────┤
│                                  │
│          光核收束动画              │
│         正在制作卡片               │
│      保留当前布局的骨架轮廓          │
│                                  │
├──────────────────────────────────┤
│              [取消制作]            │
└──────────────────────────────────┘
```

- 不显示无依据的百分比或旋转 spinner。
- 骨架轮廓应近似最终预览比例，降低状态切换时的布局跳动。
- 动画只解释“已接收操作并正在生成”，不是装饰性持续表演。
- 取消是唯一动作；关闭与取消采用同一中止语义，防止产生后台孤儿任务。

#### preview

```text
┌──────────────────────────────────┐
│ 流光卡片核                 制作完成 │
├──────────────────────────────────┤
│                                  │
│       最终 PNG 等比预览            │
│    hover / focus 后停止轻微旋转      │
│                                  │
│ 3:4 · 1200 × 1600                 │
├──────────────────────────────────┤
│ [返回修改]          [确认保存]      │
└──────────────────────────────────┘
```

- 预览使用真实 artifact，不制作假卡片占位图。
- 预览区使用足够留白展示卡片轮廓，不叠加标签或装饰文字。
- 尺寸信息属于真实导出元数据，可显示在预览下方。
- “确认保存”是唯一高强调按钮；确认完成后原位显示成功状态。

#### error

- 在原状态对应区域展示简明错误，不使用悬浮 toast 取代关键错误。
- 保留草稿、选项和可用预览。
- 提供“重试”和“返回修改”，不得同时出现语义重复的第三个主要操作。

### 17.8 控件与可访问性

- 所有输入保留可见 label，不把 placeholder 当 label。
- 点击目标最小 `40 × 40px`，主要按钮最小高 `44px`。
- 键盘顺序：关闭 → 正文 → 恢复 → 风格 → 比例 → 开关 → 重新选择 → 主操作。
- 分段选择使用原生 radio 语义，开关使用 checkbox 语义，不用仅靠 `div` 模拟。
- `:focus-visible` 使用 `2px` 强调色轮廓与 `2px` 间距，不依赖阴影表达焦点。
- 选中状态同时使用背景、边框和字重，不只依赖颜色。
- 禁用状态保留可读标签，并提供原因文本。
- 主要按钮文字和表单文本达到 WCAG AA；大字号状态标题至少达到 3:1。
- 成功、错误和制作完成使用 `role="status"` 或合适 live region，但拖动过程不播报坐标。
- reduced-motion 下禁用光核聚合、预览旋转和拖动回弹，只保留不超过 `120ms` 的淡入或即时切换。

### 17.9 动效清单与动机

| 动效 | 目的 | 规格 | reduced-motion |
| --- | --- | --- | --- |
| 面板出现 | 建立选择到编辑的状态迁移 | `opacity 0→1`，`translateY 8→0`，`180ms` | 即时显示 |
| 拖动反馈 | 表明面板已被抓取 | 阴影和 `scale(1.005)`，不改变布局 | 仅阴影 |
| 分段选择 | 确认选项已改变 | 背景与边框 `140ms` | 即时切换 |
| 制作动画 | 表明请求已开始并等待渲染 | `900-1400ms` 光核与少粒子 | 静态骨架 + 文案 |
| 预览进入 | 连接生成与最终成品 | `opacity` 与 `scale(.985→1)`，`220ms` | 即时显示 |
| 预览摆动 | 表达成品卡片的物理感 | 仅 `rotateY(-6deg↔6deg)` | 静态 |
| 按钮按下 | 提供触觉反馈 | `translateY(1px)` 或 `scale(.98)` | 可保留 |

禁止事项：

- 不使用页面滚动监听驱动装饰动画。
- 不持续动画整个面板背景。
- 不让风格选择、按钮和面板边框同时流光。
- 不使用自定义鼠标指针、磁吸按钮、无限粒子或复杂 3D。
- 不在生成阶段伪造精确进度。

### 17.10 布局验收清单

- `360px` 桌面宽度下，所有操作无需横向滚动。
- `320px` 视口下，面板保持在视口内，按钮文字不换行。
- 正文达到最大编辑高度时，仅中部区域滚动，标题和主操作始终可见。
- 风格、比例和开关可通过键盘完成操作。
- 选中、焦点、禁用、错误不能只靠颜色区分。
- editing、generating、preview、error 在同一外壳内替换，无第二层模态卡片。
- 默认主题只有一个强调色，四种卡片风格不污染面板全局颜色。
- 制作动画、预览旋转和拖动反馈均可说明其状态意义。
- reduced-motion 下流程完整且没有无限动画。
- 页面缩放到 `200%` 后，面板仍可操作且不遮挡固定动作区。
- B站浅色和深色页面背景下，面板边界、文字和焦点仍清晰。
- 所有文案经过自检，不出现重复操作意图或含糊状态描述。
